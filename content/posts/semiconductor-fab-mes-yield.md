## 先认清楚谁是谁

聊芯片制造，先把产业链分工搞清楚，不然新闻都看不懂：

| 角色 | 干什么 | 代表公司 |
|------|--------|---------|
| Fabless 设计 | 只设计芯片，不建厂 | 华为海思、联发科、英伟达 |
| Foundry 代工 | 只制造，不设计 | 台积电、中芯国际、华虹 |
| OSAT 封测 | 封装 + 测试 | 长电科技、通富微电、日月光 |
| IDM 全包 | 设计制造封测一条龙 | 三星、英特尔 |
| 设备/材料 | 卖铲子的 | ASML（光刻机）、应用材料、信越（硅片） |

国内格局一句话：设计能力强（但先进制程流片受限）、制造在追赶、封测全球第一梯队、设备材料国产化率低但增速快。

"流片"（Tape-out）= 设计公司把版图交给代工厂开始生产，相当于芯片界的"上线发布"——区别是一次先进制程流片几千万起，失败重来。所以芯片行业极度厌恶错误，这个行业性格决定了它所有 IT 系统的设计取向。

## 从沙子到电路：八大工艺循环

**第一步：造晶圆。** 石英砂提纯到 99.9999999%（9 个 9）→ 拉晶长成单晶硅锭 → 切片 → 抛光 → 晶圆（主流 12 英寸，一片上能做几百上千颗芯片）。

**第二步：在晶圆上"盖楼"。** 芯片是几十层电路叠起来的立体结构，每一层都要走一遍类似的循环：

| 工艺 | 白话解释 |
|------|---------|
| 氧化 | 表面长一层二氧化硅（绝缘/保护层） |
| 光刻 | 最核心最贵的一步：涂光刻胶 → 光刻机把电路图案投影曝光 → 显影。ASML 的 EUV 光刻机一台十几亿人民币 |
| 蚀刻 | 光刻胶保护不到的地方用等离子体刻掉，图案从"胶"转移到"硅" |
| 离子注入 | 把磷/硼离子打进硅里改变导电性，形成晶体管 |
| 薄膜沉积 | 铺一层新材料，准备盖下一层楼 |
| CMP 抛光 | 把表面磨平，不然楼越盖越歪 |
| 清洗 | 贯穿全程——晶圆厂将近一半的步骤是各种洗，一粒灰尘就是一个坏点 |
| 量测/检测 | 每做几步测一次：膜厚、图案偏移、缺陷 |

记忆主线：**光刻画图 → 蚀刻雕刻 → 注入改性 → 沉积盖楼 → 抛光磨平 → 循环几十层。** 先进芯片总计 1000+ 道工序、耗时 2~3 个月。

**第三步：测试封装。** CP 晶圆测试（探针逐颗测试，坏的打墨点，良率第一次见分晓）→ 切割 → 贴片 → 键合 → 塑封 → FT 终测 → 出货。趋势词是先进封装：Chiplet 把几颗小芯片拼成一颗大的，2.5D/3D 堆叠（HBM 内存就是叠起来的）——制程被卡的背景下，先进封装是国内提升芯片性能的现实路径。

## 为什么说半导体 Fab 是"MES 天花板"

普通工厂的 MES 逻辑在半导体工厂全部被推到极限：

- **Lot（批次）**：25 片晶圆装在一个 FOUP（密封盒）里作为一个批次流转，Lot 是所有跟踪的基本单位。
- **AMHS 自动物料搬运**：Fab 里没有人搬东西，头顶的"天车"轨道自动把 FOUP 送到下一台设备——MES 要实时调度物流。
- **Recipe（配方）管理**：每台设备每道工序的加工参数集。**下错 Recipe = 整批报废 = 百万级损失**，所以 Recipe 版本管理、防错校验是半导体 MES 的命门。
- **WIP 跟踪 + Hold/Release**：任何异常（量测超标、设备报警）立刻把相关批次 Hold 住，查清楚才放行。这是"风控母题"在制造业的极端形态：实时监控 + 异常拦截，只是拦截对象从可疑订单变成了可疑批次。
- **SECS/GEM 协议**：半导体设备通信的行业标准（相当于半导体界的 HTTP），做设备对接必然遇到。

对做业务系统的人来说，这里每一条都能对上熟悉的母题：Lot 追溯是批次正反向追溯的极致版，Recipe 防错是"配置变更审批"的极致版，Hold/Release 是风控拦截的极致版。**业务逻辑没有新东西，新的是错误代价的数量级。**

## 良率：AI 的主战场

半导体的生命线指标是**良率（Yield）**——好品占比。1000 道工序里任何一道出问题都会砍良率，而定位"良率杀手"是个大海捞针的活：要把量测数据、设备传感器数据、CP/FT 测试结果全部关联起来分析。

传统做法靠资深工程师人肉分析几天。AI 在这里的价值最直接：**把良率杀手定位从天级缩到小时级。** 数据量巨大、特征维度极多、关联关系复杂——这是机器学习的主场。配套的还有两个系统级手段：

- **FDC**：实时监控设备传感器波形，发现异常趋势提前报警
- **APC**：根据上一步量测结果自动微调下一步工艺参数（反馈控制）

另一个正在兴起的场景是**工艺知识助手 Agent**：把老师傅经验、SOP、设备手册、历史异常处理记录做成知识库，工程师自然语言提问"XX 设备报这个警怎么处理"。架构上是 RAG + 工具调用 + 工单流转，和电商客服 Agent 同构——但容错设计完全不同：客服答错转人工就行，工艺参数错了报废一批晶圆。所以在 Fab 里，Agent 的定位是"给建议的副驾驶"，置信度分级 + 人工审批兜底是硬约束，纯自动决策没人敢上。

## 国产替代的机会窗口

主流半导体 MES 长期被 Applied Materials（FAB300/SmartFactory）和 IBM SiView 把持，国产替代梯队（上扬软件、赛美特、哥瑞利）正在风口上，一直在招全栈工程师。

这个赛道要的人画像很具体：能写 Java 微服务和前端看板，能听懂 Lot、Recipe、OEE 这些工厂黑话，最好还懂点 AI 落地。三样凑齐的人极少——这也是我花时间系统学习这个行业的原因。软件架构能力是通用的，行业知识是可以速成的，两边都占的人在窄赛道里反而好定位。
