### BackupPilot 智能备份助手

**项目概述**：自然语言驱动的备份 / 恢复与企业运维智能体，统一 BackupEngine 抽象让同一套 Agent 内核既驱动本地自研备份引擎，也接入企业备份平台完成多机巡检与运维诊断；恢复等破坏性操作由 HITL 人工审批处理，支持本地离线运行。

**技术栈**：Python + LangGraph + Pydantic v2 + MCP + httpx + SQLite + zstd + Typer

**核心功能**：

1. **Agent 编排与工具接入**：基于 LangGraph 编排意图识别、规划、执行与结果校验，使用 Pydantic schema 约束 LLM 结构化输出，离线场景使用规则解析。工具函数通过 MCP Server 和 langchain @tool 适配复用；恢复操作调用 interrupt() 暂停，人工确认后恢复执行，工具层通过 confirm 参数校验确认状态。
2. **备份引擎与平台接入**：通过 BackupEngine 接口接入本地引擎与企业备份平台，使用环境变量切换实现。本地引擎采用 sha256 内容寻址去重、zstd 压缩、mtime 增量与原子写；平台适配器通过 REST 创建任务并轮询结果，结合平台数据实现多机巡检、失败诊断与容量预测。
3. **恢复校验与诊断**：恢复时逐文件校验内容完整性与目标路径，仓库采用信封加密，并通过 scrub 检查与恢复演练验证数据。运维 SOP 结合 BM25 检索与规则匹配生成诊断结果，低置信度时返回静态字典结果。

**性能与验证**：1GB 数据首备吞吐 84 MB/s、去重压缩 4.8x，修改 1% 数据后增量备份耗时 0.7s，加密开销约 5%；通过平台后端的 HTTP 接口验证备份、恢复与巡检流程。

### LLM Gateway 统一模型接入层（Java 独立服务）

**项目概述**：统一模型接入网关。对业务暴露 OpenAI 兼容接口，网关内完成多供应商路由、熔断降级、鉴权限流、语义缓存与账单对账；业务侧修改 base_url 即可接入，切换模型只需调整配置，提供本地替代实现，支持零外部依赖运行。

**技术栈**：Java 21（虚拟线程）+ Spring Boot 3.5 + Resilience4j + Redis（可选，探测降级）

GitHub：https://github.com/c524069797/llm-gateway-java

**核心功能**：

1. **模型路由与缓存**：根据熔断状态、成本和近期延迟选择供应商，请求失败时沿降级链切换；SSE 请求以首个 chunk 确认供应商，首包前失败继续降级。语义缓存结合归一化精确匹配与相似度匹配，使用 TTL / LRU 淘汰，命中后直接返回缓存响应。
2. **鉴权与限流**：通过 API key 鉴权，使用 RPM 令牌桶与 TPM 分钟窗口限流；Redis Lua 脚本原子执行额度补充、判断和扣减。限流组件提供内存与 Redis 实现，启动时根据 Redis 可用性选择。
3. **计费与对账**：请求流水与账本分别记录，通过 Redis Stream consumer group 与 ACK 异步投递计费事件；以 requestId 唯一约束实现消费幂等，对账任务识别漏账与孤账后补偿重发。

**性能与验证**：缓存命中耗时从 35ms 降至 2.8ms，降低 92%；通过自动化脚本验证熔断、降级、恢复、限流、缓存命中与计费事件补偿。
