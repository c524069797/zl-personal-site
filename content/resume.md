**技术栈**：FastAPI + LangGraph + Qdrant + GraphRAG + Java 21 / Spring Boot 3 / Spring AI（双后端）+ React 18 + Ant Design 6 + Playwright + Docker / Nginx

GitHub：https://github.com/c524069797/enterprise-agent-platform

**核心功能**：

1. **Agent 编排**：LangGraph 四节点状态机，意图识别 → RAG 检索 + 工具调用 → 人工审批门 → 回答组装；checkpointer 按 thread 持久化会话状态，审批恢复时条件入口直接跳过前置节点继续执行。9 类业务意图采用规则 O(1) 先行 + LLM 兜底，高频路径零 LLM 开销。
2. **HITL 审批硬闸门**：数据导出、发送邮件、越权动作等敏感操作在图内暂停并生成待审批载荷，人工通过审批接口决策后恢复执行——状态机层面的硬中断，审批前动作真实不会执行。
3. **检索链路**：Qdrant 向量检索 + 关键词混合检索 → GraphRAG 关系扩展，支持 metadata 分类过滤、来源溯源与父子检索；检索证据写入审计日志，每条回答可追溯到证据来源。

### ArcFlow LLM Gateway 统一模型接入层（Java 独立服务）

**项目概述**：ArcFlow 平台的模型接入网关。对业务暴露 OpenAI 兼容接口，网关内完成多供应商路由、熔断降级、鉴权限流、语义缓存与账单对账——业务侧改一个 base_url 即接入，换模型改配置不改代码，模拟供应商模式零外部依赖一键演示。

**技术栈**：Java 21（虚拟线程）+ Spring Boot 3.5 + Resilience4j + Redis（可选，探测降级）

**核心功能**：

1. **路由打分与熔断透明降级**：多因子打分（熔断器状态定健康 + 成本 + 近期延迟）选主，供应商级熔断开闸零成本跳过，主选失败沿降级链切换、客户端全程无感；SSE 流式取到**首个 chunk** 才承诺供应商，此前失败仍可降级。
2. **鉴权与双维度限流**：API key 鉴权（401 OpenAI 风格错误），RPM 令牌桶 + TPM 分钟窗口双限流（429 + Retry-After）；Redis **Lua 脚本**把"补充—判断—扣减"做成单步原子操作，内存 / Redis 双实现启动探测自动降级——单实例零依赖，多实例即分布式。
3. **语义缓存**：归一化精确匹配 + 相似度匹配 + TTL / LRU 双淘汰，命中不调上游、不计费；实测命中耗时 35ms → 2.8ms。
4. **账单对账（最终一致 + 对账兜底）**：请求流水与账本双侧记录，计费事件经通道异步投递（**Redis Stream** consumer group + ACK），requestId 唯一约束保证消费幂等，对账任务抓漏账 / 孤账并补偿重发。

**项目成效**：25 项 P0 测试全绿；一键脚本零外部依赖自动演示"故障注入 → 熔断 → 降级 → 恢复 → 限流 → 缓存命中 → 丢事件对账归平"完整故事线，故障注入与混沌演练能力内建。

### BackupPilot 智能备份 Agent

**项目概述**：自然语言驱动的备份 / 恢复与企业运维智能体，统一 BackupEngine 抽象让同一套 Agent 内核既驱动本地自研备份引擎，也接入企业备份平台完成多机巡检与运维诊断；恢复等破坏性操作由 HITL 硬闸门守护，纯本地可离线完整演示。

**技术栈**：Python + LangGraph + Pydantic v2 + MCP + httpx + SQLite + zstd + Typer

**核心功能**：

1. **Agent 编排 + HITL**：LangGraph 八节点状态机，意图识别 → 规划 → 策略决策 → 执行 → 校验汇报；恢复等破坏性操作用 `interrupt()` 中断等待人工确认，不确认绝不落盘——备份场景误覆盖数据是最致命事故，HITL 是硬约束。
2. **双引擎架构（换引擎不换大脑）**：统一 `BackupEngine` 接口，local 自研引擎（sha256 内容寻址去重 + zstd 压缩 + mtime 增量 + 原子写）与企业备份平台适配器实现同一抽象；适配层把接口方法翻译成平台 REST 调用（Bearer 认证，备份按异步任务模型走"创建任务 → 轮询到终态"），一个环境变量切换引擎，状态图一行不改。
3. **意图理解**：LLM 结构化输出（Pydantic schema 约束）优先、规则解析兜底，保证离线可用与测试确定；实测轻量模型语义别名解析强于规则、复杂槽位抽取不稳定，用 `xfail` 如实记录——理解增益交给 LLM，安全边界交给规则 + HITL。
4. **MCP 工具暴露**：能力封装成协议无关工具函数，MCP Server（Claude Desktop 可直接接入）与 langchain `@tool` 两个薄 adapter 同源；破坏性 restore 带 `confirm` 二次门控，LLM / 外部客户端也无法误覆盖数据。
5. **企业运维 Agent**：基于平台数据实现多机巡检、失败诊断（原因分类 + 修复建议）、容量预测（几天写满 + 扩容建议）、策略合规检查与四合一运维报告；`ops` 意图复用既有状态图零改动接入，命令行与自然语言对话双入口。
6. **数据安全**：恢复逐文件校验拒写坏数据 + 恢复演练 drill、路径穿越防护、SQLite 并发安全；备份仓库信封加密（scrypt 派生密钥 + AES-GCM + HMAC 对象名防指纹泄露），改口令 O(1) 无需重加密。
7. **回测强化与诊断 RAG**：scrub 全仓健康检查（损坏注入必检出并定位受影响恢复点）+ 恢复演练例行化（run-due 挂接定期 drill，结果落执行历史）+ 特殊文件边界矩阵逐字节比对，把"备份可恢复"从一次性验证变成例行机制；12 篇备份运维 SOP 知识库 + BM25 混合检索与置信度控制，失败诊断升级为"规则兜底 + RAG 增强"，低置信自动回落静态字典。
