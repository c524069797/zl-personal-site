## 行业逻辑一句话

AI 硬件产业分三层：芯片层（云端 NVIDIA/昇腾，端侧高通/瑞芯微/乐鑫）→ 设备层（AI 眼镜、AI 玩具、录音穿戴、机器人）→ 服务层（语音链路、Agent 云服务、配套 App、订阅内容）。

行业逻辑一句话记住：**芯片决定能力边界，设备负责占住场景，服务层挣持续的钱。** 纯卖硬件毛利薄，行业共识是"硬件获客、订阅盈利"。全栈工程师主要活在服务层，兼顾设备层的联调。

几个说明市场温度的数：Meta Ray-Ban 眼镜 2025 年卖出 700 万+台；中国 2025 年智能眼镜出货 275 万台，同比 +107%；AI 录音卡片 Plaud 累计 200 万+ 用户，2026 年销售目标 5 亿美元；国产 AI 毛绒玩具单品累计出货 25 万+台。深圳 AI 产业规模约 2200 亿元——这波创业潮的中国重心就在深圳。

## 一台 AI 玩具的技术解剖

从你说话到它回答，完整链路是这样的：

```
【端侧】麦克风阵列拾音 → AEC 回声消除 → 唤醒词检测（本地小模型）
      → VAD 检测人声起止 → 音频压缩（Opus）
【传输】WiFi/4G，WebSocket 或 MQTT 长连接推流上云
【云侧】ASR 语音转文字（流式）
      → LLM / Agent（人设 prompt + 对话记忆 + RAG + Function Call）
      → 内容安全过滤（儿童产品的合规红线）
      → TTS 文字转语音（流式）
【回程】音频流式下发 → 端侧播放
【配套】手机 App：BLE 蓝牙配网、账号绑定、家长设置、固件 OTA
```

端侧芯片决定了哪些事必须上云：唤醒词检测、VAD 在端侧跑，LLM 对话上云——这就是**端云协同**，AI 硬件的基本架构假设。AI 玩具的标配主控是乐鑫 ESP32（几块钱的 WiFi/蓝牙 MCU），深圳创业公司几乎人手一颗。

## 核心工程指标：延迟

用户说完话到听见回答，**超过 2 秒体验就崩，自然对话的红线是 500ms**。优化手段全在"流式"上：ASR 边听边转、LLM 首 token 尽快吐、TTS 边生成边播，三段管道叠起来。另外必须支持**打断**——用户插话时立刻停播重听。这些是语音 Agent 区别于文字 Agent 的核心难点。

技术栈正在发生范式迁移：传统 ASR→LLM→TTS 级联管道，正在被"原生语音进、语音出"的端到端模型取代。OpenAI Realtime API 端到端 300-500ms；阿里 Qwen-Omni 纯音频约 211ms；字节豆包实时语音主打全双工和丝滑打断。传输选型的工程结论：设备到云走 WebRTC（UDP 抗丢包、低延迟），服务器之间走 WebSocket。

想动手的话，开源项目 **xiaozhi-esp32**（GitHub 28k+ stars）是完整的入口：ESP-SR 离线唤醒、AEC、Opus 音频流、对接端到端语音模型，深圳一大批 AI 玩具就是在这套或类似方案上改的。花一两百块买个 ESP32-S3 开发板跑通它，再自己写云端 Agent 服务替换默认后端，就是一个完整的"AI 硬件全栈" demo。

## 翻车案例比成功案例更有信息量

**Humane AI Pin**：融资超 2.3 亿美元，2025 年 2 月关停，资产 1.16 亿美元卖给 HP，服务器关闭后设备变砖。死因：延迟高、幻觉多、电池差；499-699 美元 + 24 美元/月订阅双重收割；定位"取代手机"却处处不如手机。

**Rabbit R1**：卖出约 10 万台后口碑崩塌，留存率不到 8%。发布会演示的订车/点餐实际不可用。

**Friend 吊坠**：always-on 的窃听感触发隐私反弹，纽约地铁百万美元广告被涂鸦抵制。

失败共性总结成检查清单：

1. 和手机正面竞争（必输——手机 App 已经有 AI 了）
2. 云依赖延迟 + 电池拉胯，体验低于预期
3. 订阅疲劳：硬件贵 + 强制月费
4. 硬件发货后无法像软件一样快速迭代，第一版翻车基本就是判死刑

活得好的（Meta Ray-Ban、Plaud）共性：定位是手机的**增强和补充**，接入既有工作流；可靠性优先于炫技；订阅是可选增值。AI 硬件的生死题就一句：**你是手机的补充还是替代？到目前为止，想替代手机的都死了。**

## 硬件即 Agent 的身体

我把 AI 硬件理解成"给 Agent 一个身体和常驻场景"：AI 玩具是住在毛绒玩具里的陪伴 Agent，AI 眼镜是挂在脸上的随身助理 Agent。跟纯软件 Agent 比，多了四个工程课题：

1. **实时性**：流式架构是必修课（前面讲过）
2. **记忆与人设**：陪伴类产品的留存靠"它记得我"——长期记忆系统（对话摘要、用户画像沉淀）是核心竞争力
3. **内容安全**：儿童产品是强监管场景，生成内容过滤是合规红线
4. **离线兜底**：断网时端侧要有基础应答，端云协同的降级设计

有意思的是供应链侧的推论：深圳 turnkey 方案商能做到"模具 3-7 天、ESP32 语音模组 + 云端 LLM 对接、月产能 15 万台"，芯片成本个位数人民币。创业门槛极低意味着硬件本身不构成壁垒，**产品差异化全靠软件层：人设、记忆、内容、订阅运营。** 这正是软件和 Agent 工程师在这个行业的价值锚点。

## 全栈工程师的岗位地图

AI 硬件创业公司的软件团队通常 5-15 人，要的是"一个人能搞定 App + 云端 Agent 服务"的全栈：

| 方向 | 具体工作 |
|------|---------|
| 云端 Agent 服务 | 人设与对话管理、记忆系统、RAG、Function Call、内容安全 |
| 配套 App / 小程序 | 设备配网（BLE）、绑定、对话记录、家长端 |
| 设备管理平台（IoT） | 设备注册激活、在线状态、固件 OTA 灰度发布 |
| 数据与运营后台 | 激活/留存/订阅看板、对话质量分析、badcase 标注 |

我的智能客服 Agent 平台（意图识别、RAG、多轮记忆、工单兜底）迁到这个场景，云侧架构基本复用，新增的是语音流式链路和设备侧配套——前者是 Agent 工程经验的延伸，后者是大前端积累的用武之地。对既做过 Agent 又做过前端工程的人来说，这个行业的岗位画像匹配度是所有新兴行业里最高的。
